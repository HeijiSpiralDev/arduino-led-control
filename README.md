# arduino-led-control

Blink an LED with an Arduino.

## Hardware
- Arduino Mega 2560
- 1 LED
- 1 resistor 220 Ω
- Breadboard and jumper wires

## Wiring
The LED is connected to pin 3 through the resistor.

## Usage
1. Open `Led_Blink.ino` in the Arduino IDE.
2. Select your board and port.
3. Click Upload.
